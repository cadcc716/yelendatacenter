| 问题 | 结论（数字均来自 `results/summary.csv`） |
|---|---|
| 物理一致性 | 7 个模型 × 全部情景日：功率平衡、热平衡残差 < 1e-10，芯片热点 ≤ 85 ℃（耦合模型恰好贴限），任务全部按期完成，无越限。 |
| 本文机制的作用 | GPU 运行调节 + 液冷热状态耦合（M3/M4）使**冷水机组容量 1517→0 kWth**、自然冷却承担 100% 液冷热量、冷却电量 −40.8%、PUE 1.250→1.230、能源相关年费用 −8.8%～−8.9%。单独调频（M1）或单独升温（M2）只能使冷水机组降 5%/17%。 |
| 总费用 | 仅 −0.33%：GPU 年化投资占 96.4%，所有模型 GPU 均为 2099 台。论文应以能源相关费用为主要口径，并如实说明。 |
| DRO 与 SP | 本算例差异在求解间隙内（最坏期望总费用差 0.9 万元/年）；DRO 少配光伏、多配自然冷却，方向合理但幅度小，原因是有限支持+硬约束下容量已由最紧张情景决定。 |
| 样本外可靠性 | 测试集出现 40 ℃ 高温日与超出训练范围的实时峰值；无冷水机组的 M3/M4 在 40 ℃ 日各缺额 1937 GPU·h。把极端训练日加入支持集（M6）后缺额降至 755 GPU·h（较 M4 −79%），能源相关费用比 M4 高 2.7%。 |
| 储能 | 宁夏峰谷价差约 0.29 元/kWh，套利收益（≈72 元/kWh·年）低于年化成本（≈127 元/kWh·年），各模型储能均为 0；峰谷浮动 ±80% 时处于盈亏临界。 |
| 必须补的数据 | 中卫站逐时气象（当前为 NREL TMY3 Denver 替代）、B 级来源原文核对、GPU 模式与热阻实测。 |
