训练数据减少到约 60% 时，U-SP、U2、U3 的规划都已收敛（间隙 ≤1 万元），三者测试日年化总费用相差不足 0.6 万元、SLA 相同；减少到约 30% 时，三者都因训练支撑中实时峰值变低而只配 1947 台 GPU，测试日 SLA 同降至 99.85%（GPU 台数受限失约增加），费用相差 <0.6 万元，且规划间隙达 34–38 万元。**在本模型中，无论训练数据多少，条件半方差 DRO 相对经验分布规划均未表现出显著的样本外优势。** 原因是结构性的：运行可行性为硬约束，GPU 与冷源容量由支撑集中最紧张的情景决定，模糊集只改变期望运行费用的权重；而在 v2 模型下各方案运行费用对容量的敏感性很低。数据稀缺的真正风险来自支撑集遗漏峰值情景（GPU 低配），这需要通过支撑集构造（极端日、设计日、负荷设计峰值）而非概率层来应对。因此建议论文把 DRO 部分的贡献表述为“条件化有限支持模糊集提供可解释的最坏分布与稳健性校核，并优于无条件模糊集（U1）”，不宣称其显著降本。
