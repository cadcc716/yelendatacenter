# 中卫主算例仿真结果审稿分析（SCI 一区审稿人 / 能源系统建模视角）

> **分析对象**：宁夏中卫 ERA5 2014—2024 年逐时气象 + BurstGPT 188 日负荷。训练年 2014—2020，测试年 2023—2024，共 730 个测试日。
> **对比方案**：M0、M0-D、M1、M2、M3、R-SP、R-U2、R-U3。
> **数据来源**：`results/exp/rob_zw.csv`、`checks_*_zw.csv`、`hourly_Z-*.pkl`、`ops_Z-summary.csv`。
> **费用口径**：
> - 能源相关费用 = 光伏、储能、冷源的年化投资 + 年运行费用；
> - 风险调整费用 = 能源相关费用 + 失约单价 × 年化失约量；
> - 单位均为万元/年。

## 一、物理一致性与运行规律检查

### 1.1 检查结果

对 M0、M3、R-SP、R-U3 的 25 个规划情景和 730 个测试日逐时检查，结果如下：

| 检查项 | 结果 | 判断 |
|---|---|---|
| 电功率平衡式（24） | 最大残差 0（数值精度内） | 守恒 |
| 液冷热平衡式（8） | 最大残差 0 | 守恒 |
| GPU 占用 ≤ N、光伏 ≤ 可用出力、冷源 ≤ 容量 | 违背量均为 0 | 满足 |
| 芯片热点温度 | 测试日最高 85.0 ℃，等于上限；M0 规划情景为 72 ℃ | 热安全约束在测试日起作用；静态模型的规划情景留有约 13 K 的未利用裕度 |
| 液冷温度范围 | 25—53 ℃，在温区定义内；R-SP、R-U3 在测试日用到 51.5—53 ℃ 温区（仅可延期任务深锁频可用） | 合理 |
| 储能 | 所有方案配置均为 0，无同时充放电 | 由经济性决定，见 1.2（3） |
| 购电 | 峰值 3.26—3.67 MW，低于 6 MW 接入上限 | 接入约束不起作用 |
| 价格响应 | 可延期任务 46.7% 在峰段到达，但只有 5.2%—5.8% 在峰段处理；IT 功率与电价相关系数为 −0.27 至 −0.28 | 价格响应明显、方向正确 |
| 负荷跟随 | 日 IT 电量与日到达工作量的相关系数为 0.996（M3），单位工作量 IT 电耗为 1.37 kWh/GPU·h | 合理 |
| 气象响应 | 冷源日电量与日均温的相关系数：M0 为 0.14，M3 为 0.01 | **偏弱**，见 1.2（1） |
| 测试日日末积压 | 7,110—21,787 GPU·h 的可延期工作量在日末未完成 | **需说明**，见 1.2（4） |
| 低温时段机械制冷 | M0 在 <15 ℃ 时段的机械制冷散热占其全年的 29% | 由负荷导致，不是数值退化，见 1.2（5） |

结论：**守恒与容量约束全部满足，未发现代码错误**。下面 5 个现象需要在论文中说明或修正。

### 1.2 需要处理的问题

**（1）论文式（17）与主算例的计算口径不一致（必须修正）。**
- **现象**：论文 2.4 节写入了风机相似律模型（式 17），但中卫主算例使用的是常数风机电耗系数。M3 冷源电量与气温几乎不相关（相关系数 0.01）正是这个原因。
- **背景**：变工况风机模型只在典型气象年算例中做过稳健性检验，冷源电量与气温的相关系数为 0.78—0.86，结论不变。
- **建议**：用变工况风机模型重算中卫主算例，或在论文中说明主算例采用常数风机电耗、式（17）只用于敏感性分析。前者更好，因为它能使"冷却电量降低 24%"这一结论与主算例一致。

**（2）训练期与测试期的负荷分布差异很大（必须说明）。**

| 时期 | 实时任务均值/(GPU·h/h) | 日峰值均值 | 1% 最高小时值 | 最大值 | 超过 N=2484 的小时占比 |
|---|---|---|---|---|---|
| 训练（113 个负荷日） | 423 | 1,210 | 1,531 | 2,483 | 0 |
| 测试（47 个负荷日） | 747（+77%） | 2,008（+66%） | 2,602 | 3,527 | 1.6% |

- **原因**：BurstGPT 后期数据的对话流量明显高于前期，而负荷按时间顺序划分，后期数据全部落入测试集。这是数据本身的特性，不是代码错误。
- **影响**：
  - 所有方案共有的 GPU 台数不足导致失约，实时任务 81,228 GPU·h，可延期任务 SLA 只有 96.5%。按失约单价折算，约 520 万元/年，占风险调整费用的约 50%，与规划方法无关；
  - 因此，"按年份外推的样本外检验"同时检验了气象外推和**负荷增长**，而且后者是失约的主要来源（见第三节）。
- **建议**：在论文中明确写出训练期与测试期的负荷差异。可选两种处理：
  - 把它作为"负荷增长外推"情景直接报告；
  - 分别对两段负荷归一化后再检验，以分离气象与负荷的影响。

**（3）储能和接入约束不起作用，SOC 约束未被检验。**
- **经济性原因**：储能年化成本约 121 元/kWh。峰谷价差 0.381 元/kWh，按每天一次完整充放电、往返效率 0.85 计算，年套利收益上限约 118 元/kWh，低于成本；而且谷段（9—17 时）与光伏出力重合，实际可套利空间更小。
- **另一个原因**：购电峰值远低于接入上限。
- **影响**：模型中的储能与 SOC 约束没有被算例检验。审稿人会认为"算—电—冷"中的"电"只有光伏起作用。

**（4）可延期任务不跨日结转。**
- **现象**：代表日模型按日首尾积压为 0 设计。测试日负荷较高时，日末未完成的工作量在评价中计入失约，但不结转到次日。
- **影响**：可延期任务失约可能被高估（实际可在次日低负荷时段补做）。由于各方案同样处理，**不影响方案间的比较**，但会抬高风险调整费用的绝对值。

**（5）M0 在低温时段使用机械制冷不是数值退化。**
- **现象**：M0 的低温机械制冷集中在 1,132 个 <15 ℃ 的小时，其中 57% 的小时负荷率超过 0.6，液冷热负荷均值 1,798 kWth，高于 M0 的干冷器容量 1,504 kW。
- **结论**：静态模型按季节平均气温和 32 ℃ 设计供液配置干冷器，负荷较高时即使冬季也需冷水机组补足。这是物理上合理的结果，与早期发现的"弃光时段冷源选择退化"不同。

## 二、不同方案与基准的定量比较

### 2.1 GPU 调节与热状态反馈对配置的影响（M0—M3）

| 方案 | 光伏/kWp | 干冷器/kW | 冷水机组/kW | 冷源投资 | 光伏投资 | 运行费用 | 能源相关费用 | 冷却电量/MWh | PUE | 光伏利用率 |
|---|---|---|---|---|---|---|---|---|---|---|
| M0 | 3,957 | 1,504 | 1,715 | 48.8 | 135.9 | 362.6 | 547.3 | 423 | 1.2385 | 86.9% |
| M0-D | 3,956 | 1,516 | 1,895 | 53.2 | 135.8 | 362.7 | 551.7 | 422 | 1.2384 | 86.9% |
| M1 | 2,602 | 2,300 | 1,292 | 43.2 | 89.4 | 400.3 | 532.8 | 410 | 1.2378 | 95.9% |
| M2 | 3,970 | 1,500 | 1,609 | 46.3 | 136.3 | 362.1 | 544.8 | 423 | 1.2385 | 86.9% |
| M3 | 2,612 | 2,965 | 97 | 18.6 | 89.7 | 397.2 | 505.5 | 377 | 1.2346 | 97.7% |

**现象 → 原因 → 机制：**

1. **M3 降本的构成**：M3 比 M0 低 41.8 万元（−7.6%），由三部分组成：光伏投资 −46.2、冷源投资 −30.2、运行费用 +34.6。
   - **光伏**：M0 按"GPU 全部常开"规划，高估了午间负荷；在可休眠运行下光伏利用率只有 86.9%（M3 为 97.7%）。这部分节约来自 GPU 调节（M1 已得到 −46.5），与热耦合无关。
   - **运行费用**：光伏减少导致购电增加，运行费用上升。
   - **冷源**：冷源投资下降是热耦合的独有贡献。
2. **冷水机组的取消来自两种机制的交互**：
   - M1（只有 GPU 调节）仍有 1,292 kW 冷水机组，M2（只有热反馈）仍有 1,609 kW；冷源投资的主效应分别只有 −5.6 和 −2.5 万元，交互效应为 −22.1 万元（73%）；
   - **机理**：M1 采用静态冷却模型，看不到"降频后可升温"的价值；M2 能升温，但标称模式在 45 ℃ 以上不满足热安全，最热时段仍需冷水机组。两者结合后，浅锁频把实时任务的安全供液温度提高到 50.2 ℃，最热小时的自然冷却可用系数由 0 变为正值，单价约为冷水机组 1/4.3 的干冷器就能替代冷水机组；
   - **测试年最热日（38.9 ℃）验证**：M0 当日机械制冷电量 838 kWh，M3 只有 36 kWh，液冷温度运行到 50 ℃。
3. **交互项的数值精度**：M2、M3 的求解间隙分别为 16.7 和 13.4 万元，与交互项 −24.8 万元同量级，因此交互项数值不宜精确到个位。但冷水机组 1,609 → 97 kW 的结构变化远大于间隙可能造成的差异，"交互作用主导冷源结构变化"这一定性结论可靠。
4. **PUE 只差 0.004**：空气侧冷却按固定系数计算（约占 IT 功率 8.5%），且主算例采用常数风机电耗。论文不宜以 PUE 作为论据，应以冷源容量、冷却电量和费用为主。

### 2.2 规划—运行协同（设备容量均取 M3）

| 运行方式 | 年运行费用 | 实时 SLA | 不可安全运行测试日 |
|---|---|---|---|
| M0 方式（全部常开 + 固定 25—32 ℃） | 701.2* | 98.47% | 306 |
| M1 方式（可休眠降频 + 固定 25—32 ℃） | 376.7* | 97.54% | 246 |
| M2 方式（全部常开 + 温区控制） | 704.2 | 96.10% | 0 |
| M3 方式 | 397.2 | 99.34% | 0 |

\* 只统计可运行日。

**机理**：
- **"不可安全运行"的直接原因**：空闲 GPU 的基础发热不能削减。M0 方式下 2,484 台 GPU 全部常开，液冷基础热负荷约 1,131 kWth。固定 25—32 ℃ 供液时，温暖时段的自然冷却可用系数很低，而 M3 容量几乎没有冷水机组，即使允许失约也无法满足热平衡。
- **M1 方式**：休眠可降低基础发热，但仍固定低温供液，不可运行日减少到 246 天。
- **M2 方式**：可升温，但不调节 GPU，45 ℃ 以上只能停用实时任务，SLA 最低。

这一结果有力支持"规划与运行必须协同"。但需如实写明：传统方式不可运行的直接原因是"不休眠时的基础发热 + 低温供液"，而不只是"热耦合"。

### 2.3 不确定性处理方法对比

| 方案 | 干冷器/kW | 冷水机组/kW | 能源相关费用 | 冷却受限失约（测试日合计）/GPU·h | 设计日失约 | 风险调整费用 |
|---|---|---|---|---|---|---|
| M0 | 1,504 | 1,715 | 547.3 | 0 | 0 | 1,066.6 |
| M3 | 2,965 | 97 | 505.5 | 4,219 | 0 | 1,047.6 |
| R-SP | 1,500 | 0 | 479.0 | 523,128 | 9,085 | 3,880.2 |
| R-U2 | 3,224 | 0 | 505.1 | 3,868 | 0 | 1,045.3 |
| R-U3 | 3,224 | 0 | 505.1 | 3,868 | 0 | 1,045.3 |

**按逐时数据对冷却受限失约进行归因：**

| 方案 | 按气温分布 | 按负荷率 AR/N 分布 |
|---|---|---|
| M3 | 92% 在 30—35 ℃，8% 在 35—45 ℃ | 35% 在 0.9—1.0，65% 在 >1.0（负荷饱和） |
| R-U3 | 91% 在 30—35 ℃，9% 在 35—45 ℃ | 35% 在 0.9—1.0，65% 在 >1.0 |
| R-SP | **26% 在 <15 ℃**，各温度段都有 | 70% 在 >0.8 |

**现象 → 原因 → 机制：**

1. **R-SP 的失效主要由负荷引起，而不是由罕见高温引起**：
   - R-SP 的 1,500 kW 干冷器低于 GPU 满载时的液冷热量（浅锁频 2,005 kWth，标称 2,174 kWth），因此在测试期的高负荷时段，即使冬季也无法排出热量；
   - 训练期负荷较低，R-SP 的目标函数对干冷器容量几乎不敏感（1,983 kW 与 1,500 kW 的目标值只差约 0.7 万元，局部搜索选了候选网格的下限 1,500 kW）；
   - 因此，R-U3 相对 R-SP 低约 2,835 万元的差距，主要反映 R-SP 在负荷增长下的冷却能力不足。**论文不应把这一差距归因于"罕见高温"。**
2. **R-U3 的储备由设计极端日驱动，而设计日同时是高温与高负荷的复合工况**：
   - 设计日按训练期最大负荷日构造。最坏分布把该日的概率由 0 提高到 0.111，使干冷器容量（3,224 kW）超过满载液冷热量，冬季和一般高负荷时段不再缺冷；
   - 准确的表述是：所提模型为"高温 + 高负荷"复合极端保留冷却储备。
3. **R-U3 仍未消除负荷饱和时段的冷却失约**：
   - 测试期有 1.6% 的小时实时负荷超过 GPU 总数。此时所有 GPU 必须以标称模式满速运行（浅锁频会损失 5% 吞吐量），而标称模式只能在 ≤45 ℃ 的温区运行；
   - 在 30—35 ℃ 的气温下，45 ℃ 以下温区的自然冷却能力不足以排出满载热量，因而产生冷却失约；
   - M0 有冷水机组，不受此限制，冷却失约为 0；
   - **这是"以降频换升温"机制的内在代价**：负荷接近饱和时，降频的吞吐量损失与高温运行之间存在冲突。训练期负荷从未超过 N，所以规划模型看不到这一代价。
4. **与 M3 相比，R-U3 的增益很小**（风险调整费用低 2.3 万元，冷却失约少 8%）。R-U3 比 M3 多配约 260 kW 干冷器并取消冷水机组，但对负荷饱和时段的失约改善有限。
5. **R-U2 与 R-U3 结果完全相同**：在本算例中，正负半方差相对对称二阶矩没有带来配置差异。

## 三、能够支撑的创新点与边界

| 创新点 | 支撑证据 | 证据强度 | 必须写明的边界 |
|---|---|---|---|
| 1. GPU 调节与液冷热状态耦合改变冷源配置 | 冷水机组 1,715 → 97 kW；冷源投资节约中交互效应占 73%；最热日机械制冷电量 838 → 36 kWh | **强**（结构性变化远大于求解间隙） | 节约中约一半来自光伏规模（GPU 调节）；负荷饱和时段存在冷却失约代价 |
| 2. 规划与运行协同 | 同一容量下，传统运行方式分别有 306、246 天不可安全运行 | **强** | 不可运行的直接原因是"不休眠时的基础发热 + 低温供液" |
| 3. 风险成本型条件 DRO 为复合极端保留冷却储备 | R-U3 相对 R-SP 显著降本；设计日零失约；相对 M0 的风险调整费用显著降低 | **中** | R-SP 的失效主要来自负荷增长而非高温；R-U3 相对硬约束 M3 的增益很小；R-U2 = R-U3 |

**不应在论文中出现的说法：**
- "所提方法为罕见高温工况保留冷却储备"——应改为"为高温与高负荷复合极端工况保留储备"；
- "正负半方差模糊集优于对称模糊集"；
- "PUE 显著降低"；
- 以 R-SP 的 2,835 万元差距作为 DRO 价值的主要论据，而不说明负荷增长的作用。

## 四、修改建议（按优先级）

1. **主算例改用变工况风机模型重算**，使论文式（17）与计算口径一致。约 3 小时；预计冷却电量降幅会增大，结论不变。
2. **明确报告训练期与测试期的负荷差异**，并增加一组"负荷分段归一化"的对照，把气象外推和负荷增长的影响分开。
3. **在支撑集中加入"负荷增长设计日"**（设计高温 × 训练期负荷 × 增长系数），或把 GPU 台数纳入风险成本决策。这样可让模型内生地考虑负荷饱和时段的冷却需求，直接回应 2.3 节第 3 点的代价。
4. **评价器中可延期任务改为跨日结转**，降低失约绝对值的偏差。
5. **报告求解间隙对交互项的影响**；储能不起作用的原因在算例中用一句话说明，或增加需量电费场景。
