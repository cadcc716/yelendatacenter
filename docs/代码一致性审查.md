# 论文模型（`doit` 式1–18）与代码一致性审查

审查对象：`code/config.py`、`code/data_prep.py`、`code/model.py`、`code/run_all.py`（审查时版本 commit `21bc716`）。
结论分三类：**A 一致**；**B 代码增加、论文未说明**（不改变模型含义，需在论文补写）；**C 真正的问题**（与论文不一致或会造成错误结果，必须修改）。

## 1 逐式核对

| 论文式 | 内容 | 代码实现 | 判定 |
|---|---|---|---|
| (1) | $\sum m\le N$；$U^r\le\Delta t\sum v m$；$P^{IT}=Np^{sl}+\sum(p-p^{sl})m$；$m\ge0$ | 三组约束逐项一致；$p_{rk}$=GPU 模式功率+主机分摊，$p^{sl}$=GPU 空闲+主机分摊，同一计量边界；$p_{rk}>p^{sl}$ 成立 | A |
| (2) | $U^R=A^R$；$B_{t+1}=B_t+A^B_t-U^B_t$，$B\ge0$ | 一致 | A |
| (3) | $\sum_{\tau\le t}U^B\ge\sum_{\tau\le t-D}A^B$（$t>D$），$B_1=B_{T+1}=0$ | 一致（单行求和约束）；调度日起点取 6:00 | A；起点见 B3 |
| (4) | $C_w(T^w_{t+1}-T^w_t)=\Delta t[\beta P^{IT}-\sum(q^{FC}+q^{MC})]$ | 一致，符号方向正确 | A |
| (5) | $\sum_j u_{jt}=1$，$\sum\underline T_ju\le T^w\le\sum\overline T_ju$，$t=1..T+1$，初末 $T^w_0$ | 一致 | A |
| (6) | $\mathcal J^{safe}_{rk}=\{j:\overline T_j+R^{th}_{rk}h_{rk}\le T^{chip,max}\}$ | 一致（$h_{rk}$ 取 GPU 模式功率，偏保守） | A |
| (7) | $m\le N^{max}\sum_{j\in safe}u_{jt}$ 与 $u_{j,t+1}$ | 两端点均实现；**大 M 用 $\min\{N^{max},A^R_t/v_k\}$ 或 $\min\{N^{max},\sum_{\tau\le t}A^B_\tau/v_k\}$，并给 $m$ 加同样上界** | B1 |
| (8) | $q^{FC}_j\le\underline\phi_jK^{FC}$，$q^{FC}_j\le\underline\phi_jK^{FC,max}u_j$ | 一致；$\underline\phi$ 的计算公式论文未给出 | A；B2 |
| (9) | $q^{MC}_j\le K^{MC}$，$q^{MC}_j\le K^{MC,max}u_j$ | 一致；$a^{MC}$=1/COP 的温度修正公式论文未给出 | A；B2 |
| (10) | $P^{PV}\le K^{PV}g^{PV}$，$0\le P^{grid}\le P^{grid,max}$ | 一致（不售电、允许弃光） | A |
| (11) | 储能电量递推 | 一致 | A |
| (12) | SOC 上下界；$P^{ch},P^{dis}\le P^B$；**$b\in\{0,1\}$ 互斥**；$P^B\le c^{max}E^B$；初末 SOC | **代码把 $b$ 松弛为连续变量（RELAX_B=True）** | **C1** |
| (13) | 电功率平衡与 $\kappa_{aux}$ | 一致 | A |
| (14) | 容量上下界，$N\in\mathbb Z_+$ | 一致 | A |
| (15) | $C^{plan}=\sum a_ix_i$，$a_i$ 含寿命、折现率、固定运维 | 一致（CRF+固定运维，分设备寿命） | A |
| (16) | $C^{op}=\Delta t\sum[c^eP^{grid}+c^{var,B}(P^{ch}+P^{dis})]$ | 一致；$c^{var,B}=0$ 按论文"无可验证数据时不另计" | A |
| (17) | $\hat\mu_d$=**条件经验特征均值**；$\rho_{\ell,ds}=a_\ell^\top(F_{ds}-\hat\mu_d)$；$\delta_d$、$v^\pm$ **由训练数据估计并经验证集校准**；**求解前验证 $\mathcal P_d\ne\varnothing$** | ①$\hat\mu_d$ 取 $\sum_s\hat p_sF_s$（k-medoids 支撑上的加权均值），不是经验均值；②bootstrap 半偏差以训练均值为中心，支撑点 $\rho$ 以 $\hat\mu_d$ 为中心，**参考点不一致**；③**未做验证集校准**；④非空性只检查了均值约束，未检查二阶约束；⑤κ<1 时 $v^\pm$ 被乘以 $(1+\kappa)/2$，可能小于 $\hat p$ 的经验半偏差，模糊集含义改变 | **C2、C3、C4** |
| (18) | $\min C^{plan}+\sum_dn_d\max_{p\in\mathcal P_d}\sum_sp_{ds}Q_{ds}(x)$ | 内层 LP 强对偶重构为单一 MILP，一致；统计指标时按 $Q_{ds}(x)=\min C^{op}$ 固定 $x$ 重调度 | A；B4 |
| §5 | "情景规模较大时可逐次加入最坏概率分布的线性约束求解" | 未实现（用对偶重构代替） | B5 |

## 2 问题清单、影响与处理

| 编号 | 类型 | 问题 | 对已有结果的影响 | 处理 |
|---|---|---|---|---|
| **C1** | 论文有，代码改了 | 式(12) 互斥变量 $b$ 被松弛 | 基准与 6 个模型储能容量为 0，**无影响**；但峰谷浮动 ±80% 的敏感性出现 1.64 MW/4.98 MWh 储能，**松弛可能产生同时充放电**，该组结果不可靠 | 恢复 $b\in\{0,1\}$（RELAX_B=False），重跑 |
| **C2** | 与论文定义不一致 | $\hat\mu_d$ 用支撑加权均值；$\rho$ 与 bootstrap 半偏差参考点不同 | 模糊集中心偏移约 0.1–0.3 个标准差，二阶约束的基准错位；影响 M4、M6 和 κ 敏感性的最坏分布与容量（数值上小，但定义不符） | $\hat\mu_d$ 改为训练日经验均值，$\rho$ 与 bootstrap 统一以 $\hat\mu_d$ 为中心 |
| **C3** | 论文有，代码未实现 | $\delta_d$、$v^\pm$ 未经验证集校准 | 模糊集大小只由 bootstrap 95% 分位数决定，与论文方法不符 | 训练日再分为估计集/验证集（75%/25%）：在估计集上 bootstrap 得 $\delta^0,v^{0}$，取使验证集均值偏差与半偏差全部落入集合的最小放大系数 $\kappa_{cal}$；最终 $\delta=\kappa\kappa_{cal}\delta^0$ |
| **C4** | 代码错误 | κ<1 时 $v^\pm$ 乘 $(1+\kappa)/2$，可能把 $v$ 压到经验半偏差以下；非空性只检查均值 | κ=0.5 敏感性的模糊集定义与正文不符；若二阶约束导致空集，对偶问题无界 | $v^\pm=v^{emp}+\kappa\kappa_{cal}(v^0-v^{emp})_+$；用 LP 同时检查全部约束的非空性，若为空，求最小统一放大量并报告 |
| **C5** | 参数覆盖不同步 | `P_SLEEP`、`R_TH`、`A_AIR`、`MODES` 由 `TDP/P_HOST/COP_AHRI` 派生，敏感性覆盖基础参数时不会联动；`thermal_tables()` 直接读全局 `config`，忽略覆盖值；`extract()` 用全局 `P0` | 本次敏感性只改了 `R_TH/BETA_LIQ/C_W/FLOAT`，**这些都被正确使用，已有结果不受影响**；但若改 `TDP`、`DT_CDU`、`ITD_DES` 等会静默失效 | 新增 `config.params(cfg)` 统一重算派生参数，`thermal_tables`/`extract` 改用覆盖后的参数 |
| C6 | 代码健壮性 | `build()` 未传电价时读不存在的 `_price` | 无（所有调用都传了电价） | 改为显式报错 |
| C7 | 数值 | M2、M6 及部分敏感性点 900 s 未收敛（绝对间隙最高 20.5 万元） | 这些模型的费用比较误差可达 ±20 万元/年；容量结论稳定 | 时限提高到 1800 s 并行求解，报告实际间隙 |
| B1 | 代码增加 | 式(7) 大 M 收紧并给 $m$ 加上界 | 因 $p_{rk}>p^{sl}$，最优解不会让多余 GPU 运行，**不改变最优值**（第 3 节用数值验证） | 保留（`TIGHT_BIGM` 开关可切回论文原式），论文"求解方法"补一句 |
| B2 | 代码增加 | $\underline\phi_{jt}=\mathrm{clip}((\underline T_j-\Delta T_{CDU}-T_{amb})/ITD_{des},0,1)$；COP 按 ASHRAE 90.1 工况标定的 Carnot 比例、上限 8 | 决定冷源能力与电耗，影响结论的物理基础 | 保留，论文 2.3 节补写两条公式与参数来源 |
| B3 | 代码增加 | 调度日窗口 6:00–次日 6:00；BurstGPT 规模化 | 影响式(3)"日末清零"的时刻 | 保留，论文第 1 节补写 |
| B4 | 代码增加 | DRO/RO 求解后固定 $x$ 逐情景重调度 | 只影响统计指标，不影响容量；与式(18) $Q_{ds}$ 的定义一致 | 保留，论文补写 |
| B5 | 论文提及、代码未实现 | 逐次加入最坏分布约束的迭代算法 | 无（对偶重构是精确等价方法） | 实现为交叉验证工具 `solve_cutting_plane()`，验证两种方法目标值一致 |
| B6 | 场景设置 | Baseline 固定温区 [25,32] ℃、初末温度 30 ℃；耦合模型初末 40 ℃；$\hat p$ 由 k-medoids 簇占比给出；M5-RO、M6、样本外松弛均为论文模型之外的对照/扩展 | 属于实验设计，不是模型差异 | 论文实验部分说明 |

**单位与方向复核（全部一致）**：电价 元/kWh × kW × h = 元；$C_w$ kWh/K × K = kWh = kW × h；$R^{th}$ K/kW × kW = K；$C^{op}$ 元/日 × $n_d$ 日/年 + $C^{plan}$ 元/年 = 元/年；光伏单价按 kWp(DC) 计，$g^{PV}$ 为 kW_ac/kWp，口径一致；$A^r$ 以"标称模式 GPU·h"计，$v_{rk}$ 为相对速率，$\Delta t=1$ h。

## 4 修改后对结论的影响

v1 = 审查前代码结果（保存在 `results/old_v1/`），v2 = 修改后代码结果（`results/summary.csv`）。

| 模型 | 光伏 kWp | 自然冷却 kWth | 冷水机组 kWth | 能源相关费用 万元/年 | 求解间隙 万元 | 样本外运行费用 万元/年 | 样本外实时缺额 GPU·h |

| M2-热耦合 | 3140 → 3176 | 1399 → 1560 | 1255 → 1281 | 692.8 → 693.2 | 10.6 → 8.1 | 528.2 → 526.8 | 2062 → 1370 |

| M5-RO | 2955 → 2957 | 1930 → 2063 | 0 → 0 | 644.0 → 644.6 | 1.0 → 1.0 | 516.2 → 516.2 | 6441 → 3973 |

**解读**

1. **Baseline、M1 完全相同**：两者不涉及模糊集，$b$ 松弛/二进制、收紧大M、派生参数重算均不改变其最优解，说明修改没有引入意外变化。
2. **M2、M3 的差异来自求解间隙**：二者为 SP，不使用模糊集；容量变化（M2 自然冷却 +162 kWth、M3 冷水机组 0→16 kWth）对应的费用差均小于各自间隙，属于近似最优解之间的"平台"差异。核心结论（冷水机组 M2 降 16%、M3 降至 ≈0）不变。
3. **M4/M5/M6 的变化来自模糊集修正（C2–C4）**：参考点改为训练日经验均值、加入验证集校准后，模糊集变大，最坏分布更偏向"高延期负荷、低光伏"情景，M4 光伏 −92 kWp。不同版本的"最坏期望费用"对应不同模糊集，不能直接比较。
4. **M6 的结论被推翻**：v1 中 M6 时限内未收敛（间隙 20.5 万元），恰好停在保留 841 kWth 冷水机组的解上，由此得到"缺额 −79%"。v2 收敛到 2.9 万元间隙后冷水机组为 0，缺额 3543 GPU·h，仍低于 M4（−42%）但高于 Baseline。**v1 报告中有关 M6 的结论已撤回**。
5. **样本外缺额对冷源容量极敏感**：零冷水机组方案的缺额主要发生在超出训练支撑的 4 个高温日，几十 kWth 的自然冷却容量差异即可使缺额变化数千 GPU·h（M3、M4、M5 在两个版本间的变化均来自于此）。因此样本外缺额只适合作定性的风险提示，不宜作为模型之间的精确排序依据。
6. **总体判断**：修改后代码与论文模型一致（式1–18 逐项核对、V1–V3 数值验证）；本文核心机制结论稳定，DRO 与 M6 的结论需按 v2 如实改写（见报告 6.2(3)(4)）。
