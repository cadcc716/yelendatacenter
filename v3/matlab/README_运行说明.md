# MATLAB + YALMIP + Gurobi 版（v2，完整版）：运行说明

本目录为论文《计及GPU动态调频与液冷热惯性的AI算力园区算-电-热协同分布鲁棒容量规划》的 MATLAB 实现，
已包含此前补丁 v1.1–v1.4 的全部改动，不需要再单独打补丁。

## 0 从旧版本换到 v2

1. 把旧版本 `matlab\results` 文件夹**整个复制**到新版本的 `matlab\` 下（保留已算完的结果，断点续跑会接着算）。
2. 用新版本的 `matlab` 文件夹替换旧的；把 `main_all.m` 第 5 行改成你的 YALMIP 路径。
3. 若旧程序正在运行：可以让它把当前场景算完再按 Ctrl+C 停下，然后运行新版本的 `main_all`；
   不需要手动删除任何结果，v2 会自动识别：
   - v1.2 之前（下界读取有误）生成的结果 → 自动重算；
   - 前驱场景已有结果但当时未做嵌套热启动的结果（例如第 1 节先算的 S5）→ 自动重算，保证 S5 ≤ S4 ≤ S3。

电脑重启或中断后重新运行 `main_all`，已完成且有效的结果自动跳过。

## 3 统一的求解设置

- 两步法：第一步以总成本为目标求 N*（主问题时限 900 s）；第二步固定 N*，只以能源侧年化成本为目标，
  C&CG 主问题时限 1200 s、MIPGap 1e-3（相对能源侧成本）；最恶劣分布与已有割重复即判定收敛，剩余 gap 来自主问题。
- 嵌套热启动：S2←S1、S4←S3、S5←S4；上一场景最优解与第一步容量取优，作初始解、Gurobi Cutoff 与上界初值。
- 第二步后做容量邻域搜索，最多 30 次评估，逐次打印进度。
- Gurobi：12 线程、MIPFocus = 3、节点数据超过 2 GB 写硬盘；主问题求解时命令行显示 Gurobi 日志（每 60 s）。
- 全局修改求解设置：`init_env('yalmip', '路径', 'opt', struct('tl2', 1800, 'ls_max', 20), 'threads', 16)`；
  关闭 Gurobi 日志：`init_env(..., 'show_log', false)`。
- 单个场景出错时记录日志（含出错位置）并继续后续计算；强制重算某场景：`run_cases('zhongwei', {'S5'}, 'ccg', 'force', true)`。

## 4 运行中屏幕长时间没有新输出

以下阶段属正常：
- Gurobi 根节点加割平面（每轮主问题开头 1–2 分钟，界值缓慢上升）；
- 样本外测试（每 30 天打印一行，约 25 分钟一组）。

判断方法：任务管理器中 MATLAB 的 CPU 占用持续在 30% 以上即为在运行。超过 1 小时无输出且 CPU 接近 0 时，把 `run_log.txt` 发给我。
